# AI usage

This project is built with AI assistance. This file records where AI was used, so judges and contributors can separate generated work from verified behaviour.

## Tools

| Tool | Role |
|---|---|
| OpenCode / DeepSeek V4.1 Flash | Repository scaffolding, contract sketch, architecture notes, implementation drafts, test ideas, documentation review |
| Human maintainer | Product decisions, contract review, testnet deployment, wallet operations, final submission |

## Rules

- AI-generated code is treated as a draft. It must be reviewed, tested, and deployed on Diana before it is described as working.
- No private keys, seed phrases, or wallet recovery phrases are given to an AI tool.
- On-chain evidence is linked in the README only after the transaction is confirmed.
- “Verified” claims must point to a transaction, a test, or a reproducible command.

## What is not AI-generated

- Testnet transactions and signatures are produced by the maintainer's wallet and the official QoreChain tooling.
- Deployment keys stay with the maintainer.
